Rux DS

A framework-free UI kit built from Carbon v11, compiled under the rux prefix and vendored as static CSS, HTML and JS. No build step, no runtime dependency, no framework. This is the system running: the same four tools and eleven page templates a project starts from.

Tools

Portal

The component index: every compiled component, what it is for, and the link to IBM's own usage, style and accessibility guidance.

Kitchen sink

Every component rendered on one page, in every state that was captured. The markup reference: copy from here.

Builder

Compose a page from a template and a catalogue of blocks, edit its content in place, and take the result away as a file or a command.

Theme creator

Build a theme from one colour, see every token it moves against a live page, and check the contrast before you keep it.

Templates

Twelve page shapes, each a complete page with the shell already in it. A page here starts by copying the nearest one — never from scratch.

App shell

Nav and header, nothing else. The frame the others are built on.

Detail page

Document page

Search results page

Dashboard page

An overview of many things at once.

Settings page

Grouped preferences, each group a fieldset.

Wizard page

One step of a multi-step flow.

Schedule page

Starting a project

A new app is a folder in the site repository, named for its URL: an index.html started from a template or the builder's download, and one entry in switcher.json.

Starting a project is the recipe. The repository holds the source and the gates.
