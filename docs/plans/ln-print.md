# Plan: LN Guide, print and save as PDF

## Goal

Every scenario and its Reference can be printed, or saved as a PDF to share,
from a button on the page. The paper copy says what the screen says, laid out
to be read in one go rather than walked a step at a time.

## Decisions

- **One button, Print, and the browser's dialog does the rest.** Save as PDF
  is a destination in that dialog, so no PDF library is added and the page
  stays vector type, as the print rule in `tools/check.mjs` already requires
  of the scheduler's forms.
- **The button sits on a scenario's page and on its Reference screen.** The
  scenario's prints the whole walkthrough: its objective and prerequisites,
  each task with every step and what you should see, then its Reference. The
  Reference screen's prints the Reference alone.
- **The print layout is generated by `ln/tools/build-views.mjs`** from the same
  exported data as the screens, as one hidden print section per scenario, so
  the paper cannot drift from the page and atlas stays the only source.
- **`ln/print.css` styles the paper**, following `scheduler/print.css`: light
  on any theme, no background fills, a fixed root text size, and the header,
  tabs, links and buttons hidden. The print rule in `tools/check.mjs` gains it.
- **The PDF's name is the scenario's title**, with `— LN Guide`, set as the
  page title while the dialog is open.
- **Only what the export tier holds is printed.** A gap prints as the same
  "Not documented for this release" line the screen shows.

## Questions

- Is one Print button enough, or should a second button read Download PDF and
  open the same dialog?
- Should a printed step keep the ✎ blanks as lines to write on, for a reader
  who walks it on paper?
- Should the Map tab and the screen cards print too, or only scenarios and
  their Reference?
