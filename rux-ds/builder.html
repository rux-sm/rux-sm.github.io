Start from a template and see the page it makes. The preview is the real page in a frame of its own; what it cannot promise is the composition — every part is attested, the arrangement is yours, and docs/composing-pages.md §3.10 says what that means.

Grid width
Capped is Carbon's reading width, centred, and right for prose and forms. Full width is Carbon's own modifier for a page that is scanned rather than read — a board, a wide table — and only shows above 99rem.

    Take it away

    Without .html — what the export downloads as.

    A page for an existing project

    The download goes beside the project's index.html, and its paths already point at /rux-ds/. The copy is the whole <main> element, so it REPLACES a page's main region rather than filling it.

    A new app

    Make a folder named for its URL beside rux-ds/ in the site repository, save the download there as index.html, and add one entry to switcher.json. The next push publishes it. Nothing else to run: the scaffold script that used to do this left on 2026-09-12.
