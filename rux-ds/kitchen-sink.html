Release notes

Scrollable content takes role=region and a tab stop of its own, because a region a mouse can scroll must be reachable by a keyboard too.

Alpha — cluster autoscaling now respects per-node taints.

Bravo — the deployment log streams instead of polling.

Charlie — expired credentials fail closed rather than retrying.

Delta — regional failover no longer waits on the health check.

Echo — audit entries carry the actor as well as the action.

Foxtrot — the settings panel remembers its last open section.

Golf — bulk edits are applied in one transaction.

Hotel — the region picker lists only regions the account can reach.

India — long-running jobs report progress instead of a spinner.

Juliett — deleted resources are recoverable for thirty days.

Kilo — the API returns a request id on every error response.

Lima — scheduled maintenance appears in the activity feed.

Mike — permissions changes take effect without a re-login.

November — the audit export includes the filters that produced it.

Oscar — webhook retries back off instead of hammering the endpoint.

Papa — the cost estimate updates as the instance size changes.

Quebec — draft changes survive a browser refresh.

Romeo — the search index rebuilds without taking the table offline.

Sierra — service accounts can no longer be created without an owner.

Tango — the log viewer keeps its position when new lines arrive.

Uniform — deprecated endpoints warn a release before they go.
