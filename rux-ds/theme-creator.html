Theme creator

Every colour the build declares — 311 of them — on one list. Pick a base theme, change what you want, watch a real page re-render beside you. Detail level decides how many rows are showing; it hides rows, it never discards a value you set. Save keeps one theme in this browser and adds it to every rux-ds app's account panel here; Download writes the same theme to a file, so clearing the browser is not the end of it.

The contrast readout is advisory and never blocks. It covers 48 of the 311 rows — the tokens with a pairing recorded in theme-creator/scenarios.json or in the generator's own surface table. A row with no badge has not been checked, which is not the same as having passed.

Lowercase letters, digits and hyphens; not white, g10, g90, g100, geist, linear, ant-dark or spotify — those are the shipped themes, not a name you can save over.
Base theme
One of Carbon's four compiled themes. Everything you do not change stays exactly what this base already gets right. Picking one reseeds every field below.
Detail level
The twenty that set an accent. These are the only rows with a contrast check against a recorded pairing.
