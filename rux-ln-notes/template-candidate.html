Register a Supplier and Place a First Order

register a new supplier in the registry, give it terms and an address, then raise a first order against it and watch the order reach the approved state.

Draft Purchasing Registry Updated 2026-01-15
Not yet verified
This specimen describes an imaginary product and is not a record of anything performed. It exists to exercise the layout.

Objective: register a supplier, give it terms, and raise one order against it. The procedure ends when the order reaches Approved.

Prerequisite
An account with the Registry Editor role, and at least one address already on file. Create one in Address Book (REF-1042) first.

Phase 0 — Create the supplier record

Registry ➔ Suppliers ➔ Supplier Registry REF-1100

Note
A supplier reference is generated on save and cannot be edited afterwards.
#Do thisYou should see
0.1Open Supplier Registry (REF-1100)An empty registry list
0.2Choose New and fill in Name as Meridian Supplies LtdThe detail form opens
0.3Save, then read the generated referenceproduces a run-record value supplier reference — for example SUP-00417
0.4Attach a second address via Registry ➔ Suppliers ➔ Addresses ➔ Attach an AddressTwo addresses are listed

Phase 1 — Give it terms

Registry ➔ Suppliers ➔ Supplier Terms REF-1180

#Do thisYou should see
1.1Open Supplier Terms (REF-1180) and select the supplierAn empty terms row
1.2Set Payment terms to NET30 and Currency to EURproduces a run-record value payment terms code is stored on the supplier
1.3Save and reopen to confirm it heldThe supplier now shows Orderable

Phase 2 — Raise the first order

Purchasing ➔ Orders ➔ Order Desk REF-3020

Warning
An order raised before terms exist cannot be approved, and there is no way to attach terms afterwards — it must be re-keyed from scratch.
#Do thisYou should see
2.1Open Order Desk (REF-3020)The order list
2.2Add a line for WIDGET-A, quantity 5eaThe line totals against the supplier's currency
2.3Choose Approve, then follow Purchasing ➔ Orders ➔ Approvedproduces a run-record value first order number and the order reads Approved
